# 🌐 HTML Basics

A beginner-friendly **HTML practice project** created to demonstrate the fundamental concepts and commonly used elements of **HTML5** in a single webpage.

This project covers the basic structure of an HTML document and demonstrates how different HTML elements are used to create and organize web content.

### ✨ Concepts Covered

* 📄 Basic HTML document structure
* 🏷️ Headings (`h1` – `h6`)
* 📝 Paragraphs and text formatting
* 🔗 Hyperlinks and navigation
* 🖼️ Images and image attributes
* 📋 Ordered and unordered lists
* 📊 Tables
* 📝 Forms and form controls
* 🔘 Buttons
* 📦 `div` and `span` elements
* 🎞️ `iframe` for embedding external content
* 🎵 Audio and video elements
* 🧭 Semantic HTML elements such as `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`
* 💬 Comments and HTML attributes
* 🔤 Special characters and HTML entities
* 📌 Meta tags and page information
* 🖇️ Internal and external links
* 📑 Input fields, labels, dropdowns, checkboxes, and radio buttons

### 🛠️ Technology Used

* **HTML5** – Used to create the complete structure and content of the webpage.

### 🎯 Project Objective

The main objective of this project is to understand the **core building blocks of HTML** and gain hands-on experience in creating structured webpages using different HTML elements and attributes.

This project serves as a foundation for learning **CSS, JavaScript, and modern frontend web development**.

### 📚 Learning Outcome

Through this project, I gained practical knowledge of:

* Creating a structured HTML document
* Using different HTML elements appropriately
* Creating forms and tables
* Embedding external content using iframes
* Adding images, links, audio, and video
* Understanding semantic HTML
* Building the basic structure required for a webpage
